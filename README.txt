E-AUKSION - ISHGA TUSHIRISH YO'RIQNOMASI
==========================================

TALABLAR:
  - Node.js o'rnatilgan bo'lishi kerak
  - Yuklab olish: https://nodejs.org (LTS versiyasi)

ISHGA TUSHIRISH:
  1. Bu papkani istalgan joyga saqlang
  2. start.bat faylini 2x bosib oching
  3. Brauzer avtomatik ochiladi: http://localhost:3000
  4. Toxtatish uchun: Ctrl+C

MUAMMO BO'LSA:
  - Node.js o'rnatilganligini tekshiring: cmd > node --version
  - Port 3000 band bo'lsa, server.js ichida PORT = 3001 deb o'zgartiring
